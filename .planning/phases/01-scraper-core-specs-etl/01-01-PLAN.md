### must_haves
#### truths
- D-01: Scraper runs locally on Bun runtime using TypeScript.
- D-02: Modular design where each retailer has its own class/module conforming to a common extractor interface.
- D-03: Playwright (with Stealth plugins: playwright-extra + puppeteer-extra-plugin-stealth) and Cheerio are used for robust extraction.
- D-04: Zod schemas clean, validate, and normalize product data (CPUs and GPUs).
- D-05: Price strings must be parsed into clean float numbers (separating cash price and installment options).
- D-06: Technical specifications must be normalized, excluding invalid terms ("usado", "caixa", "kit upgrade", "defeito") and identifying white-label/Chinese hardware brands.
- D-07: Output must be a consolidated `produtos.json` file.
- D-08: Crawling architecture has three tiers: Tier 1 (KaBuM! API interception, Pichau dynamic, Terabyte hybrid), Tier 2 (Bench Promos affiliate link resolver).

#### prohibitions
- Must not write unvalidated data (e.g. products missing price or mandatory specifications) to the final JSON.
